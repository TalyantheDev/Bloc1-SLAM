## Faire des listes avec la balise "<ul>" et "<ol>"

### Non ordonnées

* Les bots
        *Amine
        *Mustafa
* Bot1
* Bot2
* Bot3

```
        <ul>
            <li>les bots
                <ul>Amine</ul>
                <ul>Mustafa</ul>
            </li>
        </ul>
        <ul>
            <li>Bot1</li>
            <li>Bot2</li>
            <li>Bot3</li>
        </ul>
```
### Ordonnées

1. Un
2. Dos
3. Tres
        1. Un A
        2. Dos A

```
        <ol>
            <li>Un</li>
            <li>Dos</li>
            <li>Tres
                <ul>Un A</ul>
                <ul>Dos A</ul>
            </li>
        </ol>
```
